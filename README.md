A modern, creative, and elevated executive portfolio crafted for **Piush Bhandari** — Senior Projects Leader & Water Treatment Professional with 25+ years delivering critical water, wastewater, desalination, and industrial infrastructure across India, Qatar, Maldives, and the Middle East.

## 🌊 Overview & Design System

The portfolio translates high-stakes municipal and industrial water engineering into an editorial, high-craft web experience:

- **Typography System**:
  - **Headings & Structural Display**: *Syne* & *Plus Jakarta Sans* for modern grotesque architectural precision.
  - **Editorial Accent**: *Cormorant Garamond* (italic serif) for signature emphasis (*life moving*, *people & planet*, *responsibility*, *water work better*).
  - **Technical Meta & Data**: *JetBrains Mono* for engineering metrics, capacities, and ISO certifications.
- **Color Palette**:
  - **Parchment Stone / Light Mode**: `#FAF9F5`, oyster cream `#F3F1EB`, deep forest `#07281F`, emerald `#059669`.
  - **Midnight Ocean Nocturne / Dark Mode**: `#061511`, deep pine `#0E241E`, luminous bioluminescent seafoam `#2DD4BF`.
- **Interactive Fluid Physics**:
  - Native HTML5 Canvas fluid simulation with organic concentric waves, floating micro-particles, and interactive ripple propagation reacting to cursor movement and click impulses.

## 🚀 Running Locally

The portfolio is built with clean vanilla HTML5, Tailwind CSS, modern CSS, and JavaScript. It can be opened directly or served via any HTTP server:

```powershell
# Option 1: Python HTTP Server (already tested on port 4173)
python -m http.server 4173 --directory "s:\Anti\piyushbhatiya"

# Option 2: Node.js npx serve
npx serve "s:\Anti\piyushbhatiya"

# Option 3: Double click
Open index.html in any modern desktop or mobile browser.
```
